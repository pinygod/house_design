# Белый мрамор — дизайн-проект второго и третьего этажей

Дизайн-проект отделки второго этажа трёхэтажного дома: семь помещений, около 89 м², потолок 2,75 м. Стены не меняются, в объём работ входит только отделка.

Стиль — современный минимализм:

- пол из кварцвинила «белый мрамор» (плитка 950×480×2,5 мм) по всему этажу, без порогов;
- теневой плинтус с зазором 10 мм у пола, теневой профиль у натяжного потолка;
- скрытые двери высотой 2000 мм;
- в коридоре хаотичные световые линии, в комнатах встраиваемые LED-споты;
- лестница в «чёрном мраморе», под ней марш вниз на первый этаж;
- акцент — эвкалипт (NCS ≈ S 5010-G10Y), стены тёплые молочные (≈ S 0804-Y30R), мягкая мебель в букле, графит вместо чёрного, свет 2700 K.

## Что где лежит

| Папка | Содержимое |
|---|---|
| `album/index.html` | Альбом проекта, 13 листов: обмерный план, мебель, полы, стены, потолки и свет, электрика, развёртки, ванная, двери, решения по помещениям, ведомость материалов, вопросы и порядок работ |
| `viz-3d/index.html` | Интерактивная 3D-модель в реальном масштабе (three.js r128), режимы «день» и «вечер» |
| `renders/index.html` | Галерея фотореалистичных рендеров |
| `renders/images/` | Рендеры после цветокоррекции: 7 дневных и 4 вечерних кадра |
| `renders/raw/` | Те же кадры без цветокоррекции, прямо из Blender Cycles |
| `assets/` | Исходники заказчика: план этажа, референс ванной, образец мраморной плитки, а также сжатые копии для страниц |
| `pipeline/` | Всё, чтобы пересобрать 3D-модель и рендеры (см. ниже) |
| `pipeline/tools/` | Вспомогательные скрипты: скриншоты для проверки и пакетные правки альбома, которые применялись по ходу работы |

Все HTML-файлы самодостаточны: картинки встроены, открываются в браузере без сервера. 3D-модели нужен доступ к cdnjs и jsDelivr (three.js).

## Пересборка рендеров

1. Скачать three.js r128 для экспорта сцены:
   ```bash
   cd pipeline && npm pack three@0.128.0 && mkdir -p npmthree && tar xzf three-0.128.0.tgz -C npmthree
   ```
2. Собрать страницу сцены. В `viz-src.html` вместо `__MARBLE__` подставляется base64 из `marble.jpg`; результат сохраняется как `vprev.html` и `viz-belyi-mramor.html`.
3. Выгрузить сцену в glTF через headless Chromium и Playwright:
   ```bash
   node export.js
   ```
   Получится `scene_green.glb`. Скрипт выгружает и `scene_wood.glb`, если вариант с деревом есть в сцене.
4. Отрендерить сцену в Blender Cycles (Python-модуль `bpy`):
   ```bash
   python3 -m venv bvenv && ./bvenv/bin/pip install bpy==5.1.2
   ./batch.sh
   ```
   Камеры, свет, материалы и экспозиция задаются в `render.py`.
5. Собрать галерею: `buildgal.py` делает цветокоррекцию, выравнивает экспозицию и встраивает кадры в `gal-src.html`.

`album-template-v1.html` — первый генератор альбома. Дальше правки вносились прямо в `album/index.html`, поэтому актуальная версия альбома лежит там.

## Третий этаж

Жилой этаж: спальня с балконом, два кабинета, гардероб, ванная и общая комната у лестницы. Потолок 2,6 м, пол Alpine Floor «Ратленд» 608×303×2,5 мм, акцент мягкий серо-синий (NCS ≈ S 3020-R90B). Тёплые фактуры: букле, шерсть, лён, светлый дуб. Свет только встроенный, торшеров и подвесов нет.

| Путь | Содержимое |
|---|---|
| `floor-3/album/index.html` | Альбом третьего этажа, 13 листов |
| `floor-3/viz-3d/index.html` | Интерактивная 3D-модель третьего этажа |
| `renders/index.html` | Общая галерея рендеров с переключателем этажей, кадры третьего этажа — `renders/images/f3_*` |
| `assets/plan-floor3.png`, `assets/rutland-sample.webp` | План третьего этажа и фото плитки «Ратленд» |
| `pipeline/make_floor3.py` | Генератор 3D-сцены третьего этажа из сцены второго (`viz-src.html` → `viz3-src.html`) |
| `pipeline/export3.js`, `pipeline/batch_f3.sh` | Выгрузка сцены в `scene3.glb` и рендер кадров (`render.py` с параметром `"floor":3`) |
| `pipeline/album3-body.html` | Тело альбома третьего этажа: стили берутся из альбома второго |
| `pipeline/rutland.jpg` | Бесшовная текстура «Ратленда», собрана из фото без водяных знаков |

## Ветки

- `main` — актуальная версия: акцент эвкалипт, молочные стены, мягкая мебель.
- `archive/emerald` — предыдущая версия с глубоким зелёным (изумрудом) и холодным белым.
- `variant-wood-brass` — проект в двух вариантах (А: зелёный, Б: дерево и латунь) с переключателем, рендеры обоих вариантов. От варианта Б отказались.
- `archive/album-v5` — альбом до правок: лестница вниз, стол из чёрного мрамора, небольшие шкафы, новая раскладка ванной.
- `archive/album-v6` — альбом до добавления окон в коридоре и удаления хозшкафа.
- `archive/work-screenshots` — рабочие скриншоты, по которым проверялись чертежи и 3D.
