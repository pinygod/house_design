# Белый мрамор — дизайн-проект второго и третьего этажей

Дизайн-проект отделки двух этажей трёхэтажного дома. Стены не меняются, в объём работ входит только отделка.

**С чего начать:** откройте `index.html`. На этой странице собран весь проект. Сверху выбирается этаж и раздел: планировка, альбом, 3D-модель или рендеры. Ссылки между разделами переключают страницу, ничего не нужно открывать отдельно.

## Сайт на GitHub Pages

Репозиторий готов к публикации как сайт: главная страница лежит в корне (`index.html`), рядом `.nojekyll`. Чтобы включить:

1. На GitHub откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
3. Через минуту-две сайт будет доступен по адресу **https://pinygod.github.io/house_design/**.

Сайт публичный: его может открыть любой, у кого есть ссылка. На сайте ссылки «отдельно ↗» ведут на страницы из репозитория (`album/`, `viz-3d/`, `renders/` и т. д.), а не на артефакты Claude.

## Этажи

**2-й этаж** — семь помещений, около 89 м², потолок 2,75 м (натяжной 2,70).

- Пол из кварцвинила «белый мрамор», плитка 950×480×2,5 мм, по всему этажу без порогов.
- Акцент — эвкалипт (NCS ≈ S 5010-G10Y), стены тёплые молочные (≈ S 0804-Y30R), мягкая мебель в букле, графит вместо чёрного, свет 2700 K.
- Теневой плинтус с зазором 10 мм у пола, теневой профиль у натяжного потолка, скрытые двери высотой 2000 мм.
- В коридоре хаотичные световые линии, в комнатах встроенные споты.
- Лестница в «чёрном мраморе», под маршем вверх марш вниз. Ограждение — чёрный поручень на высоте 1000 и стойки 12 мм с шагом 120, на марше свой наклонный поручень.
- Ванная по референсу заказчика: чёрный фактурный керамогранит, белый мрамор, тёмная тумба, вертикальная световая линия рядом с унитазом.

**3-й этаж** — жилой: спальня с балконом, два кабинета, гардероб, ванная и общая комната у лестницы. Потолок 2,6 м (натяжной 2,55).

- Пол Alpine Floor «Ратленд» 608×303×2,5 мм.
- Акцент мягкий серо-синий (NCS ≈ S 3020-R90B), тёплые фактуры: букле, шерсть, светлый дуб.
- Свет только встроенный, торшеров, подвесов и штор нет.
- Ванная: ванна под окном, короб инсталляции до потолка, световая линия на коробе справа от унитаза, полотенцесушитель на чёрной стене справа от унитаза, мрамор в откосах двери.
- Дверь спальни стоит в одной плоскости со стеной коридора. В гардеробе колонна целиком облицована зеркалом.

## Что где лежит

| Путь | Содержимое |
|---|---|
| `index.html` | Общая страница проекта с переключением этажа и раздела |
| `plans/index.html` | Обмерные планы обоих этажей: стены, окна, двери с марками и стороной открывания, проёмы, размеры по фасадам и по помещениям, таблицы помещений, дверей и окон |
| `album/index.html` | Альбом 2-го этажа, 13 листов: обмерный план, мебель, полы, стены, потолки и свет, электрика, развёртки, ванная, двери, решения по помещениям, ведомость материалов, вопросы и порядок работ |
| `floor-3/album/index.html` | Альбом 3-го этажа, 13 листов, тот же состав |
| `viz-3d/index.html`, `floor-3/viz-3d/index.html` | Интерактивные 3D-модели этажей в реальном масштабе (three.js r128), режимы «день» и «вечер» |
| `renders/index.html` | Галерея фотореалистичных рендеров с переключателем этажей: сначала общие виды этажа сверху со срезанными на 2,3 м стенами (`*_ov*`), затем помещения днём и вечером |
| `renders/images/` | Рендеры после цветокоррекции: `green_*` — 2-й этаж, `f3_*` — 3-й |
| `renders/raw/` | Те же кадры прямо из Blender Cycles |
| `assets/` | Исходники заказчика: планы этажей, референс ванной, образцы плитки |
| `pipeline/` | Всё, чтобы пересобрать страницы, 3D-модели и рендеры (см. ниже) |

Все HTML-файлы самодостаточны: картинки встроены, страницы открываются в браузере без сервера. 3D-моделям нужен доступ к cdnjs (three.js).

## Пересборка

Команды выполняются из папки `pipeline/`.

1. **three.js для экспорта сцен:**
   ```bash
   npm pack three@0.128.0 && mkdir -p npmthree && tar xzf three-0.128.0.tgz -C npmthree
   ```
2. **3D-модели.** В `viz-src.html` (2-й этаж) вместо `__MARBLE__` подставляется base64 из `marble.jpg`, получается `viz-belyi-mramor.html`. Сцена 3-го этажа генерируется из сцены 2-го:
   ```bash
   python3 make_floor3.py
   ```
3. **Выгрузка сцен в glTF** через headless Chromium и Playwright: `node export.js` (2-й этаж → `scene_green.glb`) и `node export3.js` (3-й → `scene3.glb`).
4. **Рендеры** в Blender Cycles (Python-модуль `bpy`):
   ```bash
   python3 -m venv bvenv && ./bvenv/bin/pip install bpy==5.1.2
   ./batch.sh && ./batch_f3.sh
   ```
   Камеры, свет, материалы и экспозиция задаются в `render.py`. Общие виды сверху: `./batch_ov.sh` (параметр `"cut"` срезает сцену по высоте, камера сама вписывает этаж в кадр).
5. **Галерея:** `python3 buildgal.py` делает цветокоррекцию и встраивает кадры в `gal-src.html`.
6. **Альбом 3-го этажа:** `python3 build_album3.py` собирает `album3-body.html` со стилями альбома 2-го этажа. Альбом 2-го этажа правится прямо в `album/index.html`.
7. **Общая страница:** `python3 build_hub.py` встраивает планировки (`plans.html`), оба альбома, обе 3D-модели и галерею в `hub-src.html`. Каждый раздел открывается в своём фрейме, поэтому стили и скрипты разделов не мешают друг другу.

`album-template-v1.html` — первый генератор альбома, оставлен для истории. В `pipeline/tools/` лежат вспомогательные скрипты скриншотов и пакетных правок.

## Ветки

- `main` — актуальная версия.
- `archive/emerald` — версия 2-го этажа с глубоким зелёным (изумрудом) и холодным белым.
- `variant-wood-brass` — 2-й этаж в двух вариантах (А: зелёный, Б: дерево и латунь) с переключателем. От варианта Б отказались.
- `archive/album-v5`, `archive/album-v6` — ранние состояния альбома 2-го этажа.
- `archive/work-screenshots` — рабочие скриншоты, по которым проверялись чертежи и 3D.

## Открытые вопросы

Полные списки — на листе 13 каждого альбома. Главное:

- направление маршей лестницы;
- точные привязки окон, особенно в коридоре 2-го этажа;
- ширина проёма между залом и коридором на 2-м этаже;
- толщина стены между кабинетами и общей комнатой на 3-м этаже: на плане сумма размеров больше общих 9490 мм, принято около 500 мм;
- высота подоконника на кухне;
- окно в гардеробе на солнечной стороне: штор нет, поэтому нужна УФ-плёнка на стекло.
